本征的工具箱

收集整理的实用在线工具集合，站点地址：[www.eigeen.com](https://www.eigeen.com)

### 本地预览

直接用浏览器打开 `index.html` 即可（会跳转到 `cn/index.html`）。

### 部署

通过 Netlify 部署，配置见 `netlify.toml`。
